# House rules: Bot Procurement Book (BOOK)

- This is a **public-tier** workshop: everything here may one day be pushed to a public repo. Put no data, no account IDs, and no private material here, including working notes, chat records and personal remarks. Private material lives outside this repository. Chapter working notes, which used to sit in each chapter as hidden `<!-- -->` notes, now live in the author's project files (`chapter-notes/`); GitHub shows hidden notes to anyone, so do not add new ones.
- The author's project registry, kept outside this repository, is the source of truth for status and links.
- Source material is read from other folders by path (for example `case-study` for the case studies and the context bank, `procurement-machines` for the Machine Cards, `bot-council\transcripts`) and quoted into the book. Nothing is copied wholesale.
- `construction-procurement-protocols` is now a ruin (`ruins\construction-procurement-protocols`, frozen 2026-11-12). Read it only to find something that did not rise, and never write into it.
- Open reminders for the book live in `REVIEW.local.md` in this folder (kept out of git by `*.local.md`). Read it at the start of a session.
- Folder layout is still to be decided. Keep to three levels and add a subfolder only when it earns its own README.
- When editing book prose, read `TONE.md` first. It holds working notes on the voice so far, not rules: let a chapter's tone shift when the subject calls for it, and ask Andre before smoothing out a shift that may be intended.
